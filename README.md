# Esports Gaming Lounge — Management Platform

Glassmorphism gaming café / LAN center management UI (React + TypeScript + Vite + Tailwind + Zustand).
Live demo: https://jmaatouk97.github.io/esports-gaming-lounge-claude/

All hardware actions and telemetry are **simulated** (see `src/services/agent.ts`). Real PC control needs the Windows client agent + a backend.

```
npm install
npm run dev
```
